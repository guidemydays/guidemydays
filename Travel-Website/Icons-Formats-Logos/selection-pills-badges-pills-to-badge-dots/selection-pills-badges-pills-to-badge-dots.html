Brain / Reference / Formatting

These are the only pills, badges & dots approved to use on the site — AND HOVER

Rules

1
Guides are exempted — this doc never governs a guide page. A guide page (Travel-Website/guides/{city_slug}.html) and its Read-About/stops-map pair run their own separate rule set end to end — assets/guide-style.css, Guide Structure.html, Stops Structure.html, and the rest of Brain/CORE RULES/. A pill, badge, or dot that happens to appear inside a guide is governed by the guide's own doc set, never by this one.
2
Every pill in a row is equidistant from its neighbors. Whatever a row's own gap value is, it applies uniformly between every adjacent pair in that row — never one gap bigger than another, never glued on one side and spaced on the other. Wrapped rows use the same gap both horizontally and vertically.
3
The "All" pill is always grey — and grey is never used for anything else. Wherever a row includes a "show everything / no filter applied" option, that pill takes the grey family, full stop. No other pill in that same row is ever grey.
4
A pill row never wraps into a second, identical-looking row. If a row genuinely needs more pills than fit on one line, give the overflow a different shape and shift it left — never let it just wrap unchanged into a pile that reads as one confusing block. Centered stays the general default otherwise; the left-shift only applies to the overflow group once a row has actually split in two.
5
A pill row always gets real space above and below it — never flush against the content before or after it.
6
Badge and Pill-to-Badge never exceed the reference size (12px / 4px 9px) — and don't shrink much below it either. That size is the ceiling for the whole badge/pill-to-badge shape family; noticeably smaller than that is drift in the other direction, not correctness.
7
All pills in the same group share one size — width and height — driven by the longest content at normal padding. Whichever pill has the longest label sets the size for the whole group; never inflate padding on the shorter ones to fake a match, and never shrink padding on the long one to force it back down.
8
Selection Pill is the anchor shape — Badge and Pill-to-Badge are always smaller than it, and neither gets squished to get there. Selection Pill's own reference is 14px / 8px 18px. A compact context may scale its padding down, but never so far it looks pinched next to Badge/Pill-to-Badge in the same row.
9
No two pills in the same row/group share a color. Every sibling in one filter/legend/badge row is a different color, no exceptions — two different meanings reading as the same pill is drift, full stop. If a row is running out of distinct colors, that's a signal to re-check the grouping, never a reason to repeat one.
10
An icon-bearing pill needs more vertical room than the plain-text reference — use the shared has-icon modifier (padding:7px 14px), never a page-local override. web-travel-style.css's --fam-pad (4px 9px) is sized for text alone; an icon taller than the text line reads squished at that padding. And per Rule 7, every pill in the same group takes the same size as its tallest sibling — if any pill in a row needs has-icon, every pill in that row does, even ones with no icon of their own.

The three forms are different sizes and shapes, not just different roles — Selection Pill is the larger fully-rounded (999px) pill, Badge and Pill-to-Badge are both the smaller 4px rounded rectangle. Selection Pill and Pill-to-Badge both hover — Badge never does, it's the one static, non-interactive form. A single pill only ever gets ONE hover type, never more than one at once — the type shown next to each color name cycles through all 4 (Darken/Lift/Press/Glow) below only to sample the full range; hover or click-and-hold any pill to try it.
