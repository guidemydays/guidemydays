Line 341: a { color: var(--accent, #8a6c1a); text-decoration: none; }. Line 342: a:hover { text-decoration: none; }. Both states suppress underline. The .reading-col a:not([class]) rule (line 248) applies underline at rest — but ONLY within that container class. Any prose link outside .reading-col (e.g. Worth Knowing, card descriptions, page footer) receives no hover signal.
