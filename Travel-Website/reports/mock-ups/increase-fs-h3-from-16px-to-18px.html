Increase --fs-h3 from 16px to 18px

Finding date: 2026-08-26 · File: Travel-Website/assets/web-travel-style.css line 149 · Change: --fs-h3: 16px → --fs-h3: 18px

Currently --fs-h3 equals --fs-body (both 16px). h3 headings only differ from body text via font-weight: 600 — there is no size hierarchy. Nomadic Matt uses h3 at 26px on a 20px body (ratio 1.3×). On a 16px body, 18px produces a 1.125× ratio — the minimum to signal a heading.

BEFORE
--fs-h3: 16px = --fs-body: 16px

h3 16px weight 600 vs body 16px weight 400 — size is identical, only weight differs.
AFTER
--fs-h3: 18px (1.125× body)
