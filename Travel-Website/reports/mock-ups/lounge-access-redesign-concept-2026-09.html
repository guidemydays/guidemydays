Design notes — not shipped, proposed for owner review

Pass card patternEach access method is a horizontal "pass" card — icon + type label left, perforation divider, conditions + key facts right. Borrows from the airport boarding-pass language without being literal about it.
Colored accent strip6 px left border per family: teal (sb-teal) for PP membership, gold (sb-gold) for Amex, terracotta (sb-terracotta) for credit cards. Draws from sb-* fill values — same semantics as the live page's .access-card.pp/.card.
Sticky sidebar"Which route is yours?" column gives readers a fast self-selection path without reading all three cards. Only added on desktop; mobile gets full-width stacked cards.
Change pills cp-* onlycp-gold "Rule changed Jul 2026", cp-terracotta "New caps 2026", cp-teal "Worldwide" — all from approved Calm Pastel family, all values from CSS variables, none hardcoded.
Pass facts stripBorder-top rule separates the brief narrative from scannable key data points (guest fees, caps). Much faster than reading the full paragraph when you just want "what's the fee."
Hero unchangedBackground, hero band, heading, subhead, and icon kept verbatim per _shared.md spec. Redesign applies only below the hero — the blank canvas starts at "How you get in."
