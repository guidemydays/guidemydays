Design Notes — Region Radar concept

  • Primary navigation shift: region tabs + search, not search-only. Readers who don't know a country name can browse by geography first.
  • Norm spectrum bar: each card pairs a Solid Badge (sb-*) chip with a color-filled bar proportional to tipping intensity — scannable at a glance, confirmed by text.
  • Card density: 220px min-width grid fills the viewport efficiently. More scannable than the current list on tablet/desktop; collapses to single-column on mobile.
  • Region filter: shows/hides region sections — no pagination, no page reload. Works alongside search (typing filters cards within the visible region).
  • Legend strip: persistent below hero, never scrolls away. Anchors the color language the reader needs to decode the cards.
  • What stays: same search placeholder text, same norm labels (Expected / Appreciated / Check the bill / Skip it), same tip text per country, same data source.
  • What changes: layout from search-list to grid; region tab navigation; visual norm bar per card. No data edits required to ship this redesign.
